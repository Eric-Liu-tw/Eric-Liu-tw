**Tech Stack:** Python, MediaPipe, Flask, Streamlit, Machine Learning

---

### 📈 Hypeboy - Stock Sentiment Analysis Platform

以社群資料為基礎的股市情緒分析平台，嘗試透過文字資料與市場情緒判斷可能的進場時機。

**Tech Stack:** Python, NLP, Sentiment Analysis, Data Processing

---

### 🗺️ Emotion-Based Location Map

一個讓使用者提交地點情緒與感受程度的 Web App，目標是建立「以情緒探索地點」的互動式地圖。

**Tech Stack:** React, Node.js, Prisma, Database Design

**Tech Stack:** LangGraph, Ollama, ChatGLM, Streamlit
